# GP1247AI Driver Board
A GP1247AI clock and animation player, the PCB can also be used as a standalone power supply for the display with external SPI communication through a 10-pin IDC connector.

The [Code](/Code) directory contains the C code for the microcontroller and Python cli tools for syncing the RTC, and writing animations to the device over USB CDC.
